System Architecture

How data travels from the camera to the cloud.

1 · Computer Vision

TensorFlow.js + Teachable Machine classify every object in the browser with a confidence threshold of 85%.

2 · BLE UART Bridge

Web Bluetooth writes the detected colour to the Nordic UART TX characteristic of the BBC micro:bit.

3 · Robot Brain

The micro:bit drives the servo/arm, then echoes the colour back as a handshake confirmation.

4 · Handshake & QC

A 12-second watchdog timer flags any missing acknowledgement as a timeout error for quality control.

5 · Realtime Database

Firebase RTDB stores each event with a timestamp; every connected dashboard stays in sync instantly.

6 · Rich Reporting

Styled XLSX, PDF and DOCX reports with the VERNOVA header, colour-coded rows and full summaries.
